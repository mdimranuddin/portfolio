# Mohammad Imran Uddin — Personal Portfolio

A fully responsive personal portfolio website built with React, Vite, and Tailwind CSS.

## 🔗 Live Demo
[View Live Site](#) <!-- ✏️ Replace # with your Vercel link after deployment -->

## 🛠️ Tech Stack
- React 18 + Vite
- Tailwind CSS
- React Router v6
- React Icons

## ✨ Features
- Dark / light mode toggle
- Typing animation in hero section
- Scroll fade-in animations
- Fully responsive on all devices
- Project detail pages with React Router
- Contact form

## 🚀 Run Locally
```bash
npm install
npm run dev
```
