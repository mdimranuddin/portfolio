# Mohammad Imran Uddin — Personal Portfolio

A fully responsive personal portfolio website built with React, Vite, and Tailwind CSS.

## 🔗 Live Demo
[View Live Site](https://mdimranuddin.vercel.app)

## 🛠️ Tech Stack
- React 18 + Vite
- Tailwind CSS
- React Router v6

## 🚀 Run Locally
```bash
npm install
npm run dev
```
